# Axell Signature Dojo - design decisions

| # | Decision | Why |
|---|---|---|
| D1 | The Dojo drives the installed plugins as a black box (JUCE's VST3 host): parameters by display name and text, factory programs, offline renders, the DAW state | Works with any plugin version; presets and chains are the plugins' own state, nothing reconstructed by hand. No plugin code changes. |
| D2 | Installs only from an archive plus its published SHA256SUMS.txt; a strict tar reader (no links, devices, `..` or absolute paths) unpacks into a private staging folder; only the plugin bundle is taken | A damaged or foreign archive can never write outside the staging folder or run a script. |
| D3 | The bundle must hold the binary and a moduleinfo.json with the release's version and vendor, and every library must resolve (ldd) before ~/.vst3 changes; the old bundle is renamed to a backup, the new one renamed into place; removing keeps a copy | Every step can be undone; nothing else in ~/.vst3 is touched. |
| D4 | REAPER chains are written in REAPER's own VST3 chunk format (header, component/controller state, trailer), reverse-engineered from REAPER 7 projects and checked byte-identical; REAPER's numeric id comes from its plugin cache (0 works too) | tools/reaper-verify.sh loads every chain in a portable REAPER copy: 11/11, all tuned values as set. |
| D5 | Workstation checks only read; fixes run only in the user's account, only after confirmation, with undo text; anything needing administrator rights is explained, never run; a sandbox never runs a fix's command | Immutable systems (Bazzite) and user trust. |
| D6 | Processes run without a shell (posix_spawn + poll, timeout, cancel) | No file or release name can be interpreted by a shell; a hung tool cannot freeze the app. |
| D7 | Loudness by ITU-R BS.1770 (axell-core, EBU Tech 3341 conformant) on the channels a plugin on the track sees | Matches what Velvet's LEARN and the plugins measure. |
| D8 | Esses measured on the shipping sibilance detector's own hops, "s" and "sh" separately, reported as cluster centres | Averaged together the stronger "sh" hides the "s"; on the artist's take a 5.6-9 kHz plateau within 1 dB. Agrees with Velvet's earlier measurement within 1/6 octave. |
| D9 | No automatic "boxy room" EQ. The low-mid balance against 27 dry studio voices (VCTK, CMU ARCTIC) is shown, flagged only at z >= 3 (1 of 27 dry voices, leave-one-out) | A long-term spectrum cannot separate a voice's formants from a booth (6 of 27 dry voices flagged at z 2); the ring-after-words method found only 4 usable word endings on a rap take. Room correction stays with Axell De-Reverb. |
| D10 | De-Reverb amount from the blind RT60 (Axell Gate's room model): < 0.2 s Gentle, <= 0.4 s Natural, else Clean | RT60 is the validated room measure (within ~15 % in Axell Gate). |
| D11 | A take with stereo content in its pauses (side within 20 dB of the centre) is flagged as processed; room-dependent settings then use safe defaults | Printed-in reverb fakes the room. |
| D12 | Rules only from measured properties: gate key, EQ high-pass and compressor side-chain from the voice's lowest notes, gate range from the noise floor, de-ess focus from the ess energy split | Taste (saturation, air) stays with the user. |
| D13 | Tuning by rendering the take: Duo FET input by bisection to a 6 dB 95th-percentile gain reduction, opto to a 3.5 dB median, Velvet LEVEL as LEARN sets it (-18 LUFS minus its input), every output loudness-matched and corrected on the whole take | Measured on the artist's take: every stage within 0.03 LU; FET re-measured on the whole take 6.8 dB. |
| D14 | Background jobs post results to the message thread; on quit running tasks are cancelled and awaited | No frozen window, no half-written files. |
| D15 | Open in REAPER writes a project (one armed vocal track holding the chain, monitoring off) and starts REAPER detached (`setsid -f`); projects never replace a file | Monitoring off avoids feedback through speakers; verified in a portable REAPER: the track is armed and holds the five plugins with every tuned value. |
| D16 | Reference Match fits bells to the difference between the reference and *what Penta EQ receives* (after De-Reverb and Gate), shape only (each normalised to its 500 Hz-4 kHz level), smoothed to 1/3 octave, limited to +-6 dB, 80 Hz-12 kHz, greedy bells (Q from the half-height width) | Fitting to the raw take left half the difference (De-Reverb and Gate change the tone first). The result is measured on the rendered take, not assumed. |
| D17 | Streaming Preview applies each service's published playback normalisation to the measured master: loud masters turned down; quiet ones turned up only by services that do so, and only as far as the true peak allows | Hearing a master at the level listeners get shows what extra loudness costs and buys. |
| D18 | Confidence per measurement from the take's own properties (voice length, clipping, gated pauses, pitched frames, ess frames, printed effects, background, sample rate) | An outside review asked the Voice Profile to say when its input is outside its tested conditions. |
| D19 | Batch Render loads a saved chain back into live plugins from the chain file itself (VST3 class id + REAPER state) | The chain renders exactly as REAPER would load it; a foreign or missing plugin is reported, never skipped silently. |
| D20 | Backup & Move: files plus a SHA-256 manifest; restore verifies every file, copies only files that do not exist, and accepts only the suite's own folders | Moving to another computer can never overwrite a preset or follow a path out of the suite's folders. |
| D21 | De-Reverb Clean (95 %) for a small room (RT60 <= 0.40 s) whose background is less than 35 dB under the voice | Measured on rooms matched to the artist's untreated room (axell-dereverb D16): 95 % is the most accurate setting (cepstral distance 2.49 vs 2.53) with 1.6 dB more room and noise removed than 85 %; `--reduction` / `--gate-range` on the terminal for presets made across several sessions. |
| D22 | The Voice Profile listens with Axell Velvet 3.0's sibilance network (axell-core `DetectorConfig::velvet3()`), the core's default staying Velvet 1.0's (Axell Gate 2.0 was trained on its output) | Trained on 111 voices instead of 3 (CMU ARCTIC + VCTK): on 12 accents it never heard F1 0.82 vs 0.72; on the artist's Romanian takes it catches more voiced and unvoiced sibilants (axell-velvet DECISIONS V19). On the artist's dry take the ess clusters stay at 3.4 / 7.8 kHz. |
| D23 | Velvet's AMOUNT is tuned on the take: the gentlest of 30-70 % (5 % steps) that brings the loud end of the esses (90th percentile of the sibilant hops' 2-17 kHz level re the voice body, measured on Velvet's rendered output at the hops where its input has esses) down to where natural speech has it: -9.4 dB, the median over 111 voices (80 % of them between -12.3 and -5.7 dB) | Natural speech is the reference nobody can argue with, and the gentlest setting that reaches it lisps least. A "no harsh esses" target (above body - 3 dB) was tried first and rejected: every AMOUNT above 25 % meets it by construction, so it always chose 30 %. On the artist's dry take (after the chain's compressor) the esses' loud end goes -1.9 -> -10.4 dB at 50 % - the setting the artist had found natural by ear. |
| D24 | With every Voice Profile chain the Dojo also writes "<name> - Tracking Chain": the same tuned plugins for recording while monitoring through them - Velvet's LIVE de-esser (zero latency), Gate at LIVE speed, no De-Reverb (it needs look-ahead) - and reports its measured latency; a "Tracking (Live)" template too | Measured on the artist's take: 3.4 ms of plugin latency (Gate 0, Penta EQ 0, Duo 1.6, Velvet 1.7 ms) instead of 70 ms with Gate's BEST speed. REAPER loads it with every value (tools/reaper-verify.sh, 14/14). An older plugin without the LIVE setting is named in the report. |
| D25 | 3.0: the tracking chain keeps De-Reverb, in its new LIVE mode (a causal network as a zero-latency filter); an older De-Reverb is left out as before. The "Tracking (Live)" template starts with it too | axell-dereverb D17: LIVE removes 3.7 dB of room (STUDIO 5.7) on 48 held-out examples with ViSQOL 4.00 (input 3.96) and no more voice damage than STUDIO, at 0 ms - the artist hears the voice without the room while recording, at the same ~3.4 ms of chain latency. |
| D26 | 3.0: the profile chains pick up the cluster's 3.0 work through the plugins themselves - Duo Compressor's VOICE HOLD (on for new instances: the pauses are no longer lifted by the compression, +23.4 -> +5.9 dB on the artist's take), Gate 3.0's two networks, Master's VOICE HOLD in its vocal presets, Penta EQ's ESS detector source - so the Dojo's tuning measures what the artist will hear | Nothing to configure in the Dojo; the tuning renders through the installed plugins (D17), so a profile made with the 3.0 plugins is tuned on their behaviour. |
| D27 | 3.0: the Axell's Dojo brand title in the sidebar: "Axell's" in gold over "Dojo" in the brush face (Yuji Syuku, SIL OFL 1.1, via axell-core BrandTitle) with the Dojo's seal 道 ("the way") | The same title, emblem and seal language as every plugin's header. |
| D28 | 3.0.1: the app icon is the Dojo's own seal - 道 carved white in a vermilion hanko seal (Yuji Syuku, worn stamp edges, ink pooling, tiny voids), stamped at -7 degrees on torn washi laid at +4 degrees, inside the brand's dry-brush gold ensō on black lacquer with a gold rim (generator: axell-brand/dojo_seal_icon.py); shipped in 8 sizes | The seal is the Dojo's mark in the sidebar and the brand's language (every plugin carries its own seal); it stays legible down to 32 px (a red stamp with 道), where the earlier emblem icon became a gold ring. Installing every size stops a desktop showing a cached older small icon. |
